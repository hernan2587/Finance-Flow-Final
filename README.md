## Description

Finance Flow is a simple web app that helps users understand their monthly finances. The app allows users to enter income, expenses, and debt to calculate their remaining balance.

## Features

- Calculates monthly balance

- Displays formatted financial summary

- Provides personalized financial advice

- Suggests savings and investment options

## How to Run the App

1. Install Streamlit:

pip3 install streamlit --break-system-packages

2. Run the app:

python3 -m streamlit run after_app.py

## Project Structure

- before_app.py → Original version

- after_app.py → Improved version using AI

- reflection.md → Explanation of improvements
